About REWIND Studio

    

      
REWIND Studio is a local-first desktop editor. Projects are JSON files with a .rwdproj extension; exported places use .rwdplace.

      
The editor connects to api.rwd.2bd.net for accounts, cloud places, assets, and published server scripts.
